└────────── тип: - файл, d папка, l ссылка
__________________________________________________
Три цифры — owner, group, others:

755 = rwxr-xr-x — владелец всё, остальные читают и выполняют. Стандарт для скриzптов.
644 = rw-r--r-- — владелец читает и пишет, остальные только читают. Стандарт для файлов.
600 = rw------- — только владелец. Стандарт для приватных файлов (SSH-ключи, пароли).
777 = rwxrwxrwx — все могут всё. Это опасно. Никогда не ставь 777 без причины.
___________________________________________________
chmod 755 script.sh         # установить права 755
chmod +x script.sh          # добавить право execute
chmod -w file.txt           # убрать право write
chmod u+x script.sh         # добавить execute только владельцу (u = user)
chmod g-w file.txt          # убрать write у группы (g = group)
chmod o-r file.txt          # убрать read у остальных (o = others)
chown vsevolod file.txt     # сменить владельца
chgrp staff file.txt        # сменить группу
chown vsevolod:staff file.txt   # сменить и владельца, и группу

Процессы

Процесс — запущенная программа. У каждого процесса:

PID (Process ID) — уникальный номер.
PPID (Parent PID) — родительский процесс.
UID — от какого пользователя запущен.
CPU% — сколько использует CPU.
MEM% — сколько использует памяти.
STATE — состояние (running, sleeping, zombie).
Команды:

bash
ps aux                  # все процессы
ps aux | head -20       # первые 20
ps aux | grep python    # только python-процессы
ps aux | sort -nrk 3    # сортировка по CPU (3-я колонка)
ps aux | sort -nrk 4    # сортировка по памяти (4-я колонка)
top                     # интерактивный мониторинг (выход — q)
pgrep -l python         # найти PID по имени
kill PID                # послать SIGTERM (мягкое завершение)
kill -9 PID             # послать SIGKILL (жёсткое убийство)
pkill -f python         # убить все процессы с "python" в имени

Сигналы:

SIGTERM (15) — вежливая просьба завершиться. Процесс может успеть сохранить данные. По умолчанию.
SIGKILL (9) — принудительное убийство. Нельзя игнорировать. Используй, только если SIGTERM не помог.
SIGHUP (1) — перечитать конфигурацию.
SIGSTOP (19) — приостановить.

Открытые файлы и соединения

lsof — list open files. Показывает, какие файлы и соединения открыты процессами.

bash
lsof -i -P                     # все интернет-соединения
lsof -i -P | grep LISTEN       # только слушающие порты
lsof -i :443                   # кто использует порт 443
lsof -p 1234                   # какие файлы открыты процессом 1234
