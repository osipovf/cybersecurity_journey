Статус-коды 200 OK — всё хорошо, запрос обработан.
201 Created — ресурс создан (после POST).
204 No Content — успех, но тела нет (часто после DELETE).
301 Moved Permanently — ресурс переехал навсегда. Браузер запомнит новый адрес.
302 Found — временный редирект. Браузер не запоминает.
304 Not Modified — контент не изменился, бери из кэша.
400 Bad Request — клиент прислал некорректные данные.
401 Unauthorized — не авторизован (нет токена/логина).
403 Forbidden — авторизован, но нет прав.
404 Not Found — ресурс не найден.
405 Method Not Allowed — метод не поддерживается (например, POST на эндпоинт, где только GET).
429 Too Many Requests — слишком много запросов (rate limiting).
500 Internal Server Error — сервер упал.
502 Bad Gateway — прокси/шлюз получил некорректный ответ от upstream-сервера.
503 Service Unavailable — сервер перегружен или на обслуживании.
